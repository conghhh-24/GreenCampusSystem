## 测试证据边界

现有 Surefire 报告共 97 项测试通过，包含 5 项 H2 评价事务集成测试；不等于已完成真实 MySQL 约束和并发验收。本轮没有重新写入验收数据库，也未删除历史数据。执行 database/integrity_check.sql 并保存结果，异常为 0 仅说明脚本覆盖范围内未发现问题。

当前业务使用具体 meeting_date，不写 meeting_day。新发布/编辑必须选择类别，历史空类别仍兼容。source_id 不是统一外键；信誉时间恢复目前没有逐笔流水，不能按信誉流水之和核验全部信誉总分。
