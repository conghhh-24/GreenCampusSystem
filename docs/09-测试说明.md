# 测试说明

测试注册登录、物品发布与类别选择、编辑后重新审核、查询下架、交易申请完成与评价、回收申请完成、积分流水、管理员查询和统计看板。验证无效外键、负数价格/重量、重复唯一值、非法状态和已完成订单修改均被拒绝。认证测试覆盖会话固定、CSRF、未登录访问、禁用用户与身份冒用；日期测试覆盖具体交接日期、过去时间、旧 meetingDay 参数、无效日期和半小时时间点。

本轮只更新文档，未重新执行应用测试。已重新读取现有 `backend/target/surefire-reports/TEST-*.xml`：9 个测试类，共 97 项后端测试，失败、错误、跳过均为 0。其中 5 项评价集成测试使用 H2 实际事务，覆盖保存后重新查询、重复与并发提交、3 分评价、失败回滚及旧状态迁移。其余测试包含模拟数据库校验。此前前端构建与 Vue 模板编译检查通过，该记录不表示本轮重新构建。

复验可在项目根目录执行 `mvn -f backend/pom.xml test`，在 `frontend` 目录执行 `npm ci` 和 `npm run build`。环境版本与配置见 [开发环境](05-开发环境.md)，接口认证示例见根目录 `demo.http`。

H2 和模拟测试不能代替真实 MySQL 的外键、CHECK、锁等待与完整用户流程验收。须重启更新后的后端、刷新前端并重新登录，执行 [功能检查指南](11-功能检查与测试指南.md)，在验收库运行 database/integrity_check.sql，保存预期、实际结果和截图。文档中的用例描述不代表真实数据库用例已执行。
