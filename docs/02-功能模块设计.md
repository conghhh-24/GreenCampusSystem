# 功能模块设计

系统功能模块图见 [function-modules.drawio](report/function-modules.drawio)，可在 diagrams.net 中继续编辑；[function-modules.svg](report/function-modules.svg) 为可直接插入报告的导出图。

系统以“用户与认证”为入口，按业务划分为物品流转、交易订单、回收管理、环保积分和统计分析五个模块，并由管理员中心负责审核、回收处理和数据查询。

1. **用户与认证**：注册、登录、退出、会话校验、角色权限、密码哈希和 CSRF 请求校验。
2. **物品流转**：物品发布与类别选择、图片上传、我的物品、编辑后重新审核、逻辑下架、关键词与处理方式查询。
3. **交易订单**：出售/赠送申请、卖家确认、买家完成、订单撤回、金额和交易安排快照；买家完成后评价，订单转为已评价并显示评分与内容。
4. **回收管理**：回收物品发布、回收点选择、未来预约、管理员确认预约、开始处理、录入重量和完成回收。
5. **环保积分**：按重量和类别系数计算积分、积分流水、信誉积分与评价记录。
6. **统计分析**：累计回收重量、完成回收次数、物品完成率、处理方式占比、回收点重量、月度趋势、平均处理天数和贡献排行。
7. **管理员中心**：物品审核、驳回意见、用户查询、回收订单处理、回收记录查询和统计看板。

物品状态由待审核、已上架、已申请、处理中、已完成组成；允许的历史操作以逻辑下架、订单撤回和回收预约撤回保留记录。
