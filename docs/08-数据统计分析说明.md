# 数据统计分析

统计由已登录用户访问 `GET /api/stats/overview`，后端在可重复读的只读事务中执行聚合查询，前端使用 ECharts 展示。累计指标覆盖全部历史数据，不受物品大厅的搜索和分页影响；只有月度趋势限定近 12 个月。

## 指标口径

| 指标 / 返回字段 | 数据来源与计算规则 |
| --- | --- |
| 累计发布 `summary.total_items` | `items` 全部记录，包含待审核、驳回、下架和取消等状态 |
| 已完成物品 `summary.completed_items` | `items.status='COMPLETED'` 的数量；覆盖出售、赠送和回收 |
| 完成率 `summary.completion_rate` | 已完成物品数 ÷ 全部物品数 × 100%，保留 2 位小数；没有物品时为 0% |
| 平均处理天数 `summary.avg_processing_days` | 仅对已完成且 `completed_at >= published_at` 的有效记录计算秒差 ÷ 86400，再取平均、保留 2 位小数；无有效记录返回 NULL，页面显示“暂无数据” |
| 累计回收重量 `summary.total_recycle_weight` | 关联预约状态为 COMPLETED 的回收记录，汇总 `weight_kg`；无记录为 0 |
| 完成回收次数 `summary.completed_recycles` | 上述已完成预约关联的回收记录数；不是回收物品发布数或预约申请数 |
| 处理方式 `methods` | 按全部物品的 SELL/GIVE/RECYCLE 分组计数及占比，包含未完成和撤回记录；后端占比保留 2 位小数 |
| 回收点统计 `stations` | `v_station_recycle_stats` 汇总已完成预约对应的记录数和重量；包含当前关闭的回收点，无记录的回收点显示 0 |
| 类别统计 `categories` | `v_category_stats` 按类别汇总物品数及非零价格均值，包含“未分类”；不限定已完成或已审核状态 |
| 环保排行 `ranking` | 用户关联 `eco_point_records`，按流水积分合计降序、用户编号升序；没有流水的用户不进入接口结果 |

交易评价将订单改为 `REVIEWED`，物品仍为 `COMPLETED`，因此评价后的交易仍计入物品完成率与完成月份。完成率分母包含所有发布记录，不能解释为“审核通过物品成交率”。

## 月度趋势

以北京时间当前月份为末月，向前包含 11 个月，共 12 个自然月。查询范围为首月第一天 00:00:00（含）至下月第一天 00:00:00（不含），本月持续累计；缺失月份由后端补 0。

| 月度字段 | 时间与状态口径 |
| --- | --- |
| `published_items` | 按 `items.published_at` 归月，包含全部状态 |
| `completed_items` | 按已完成物品的 `items.completed_at` 归月 |
| `recycle_count`、`recycle_weight` | 只取已完成预约关联记录，按 `recycling_records.recycled_at` 归月 |

例如 10 月发布、11 月完成的物品，分别计入 10 月发布数与 11 月完成数；不能将发布月份当成完成月份。月度图展示发布数、完成数与重量，展开明细还可查看回收次数。

## 视图与演示 SQL 的区别

`database/views.sql` 中的 `v_category_stats` 和 `v_station_recycle_stats` 被看板接口直接使用。`v_monthly_item_stats` 按发布月份分组，其中完成数表示“该发布月份的物品目前完成了多少”；当前看板月度趋势使用独立事件查询，不读取这个视图。

`database/queries.sql` 用于展示 JOIN、GROUP BY、HAVING、子查询及聚合函数，不能将其每条查询当作看板接口的完整复现：该文件排行使用 LEFT JOIN 并仅保留正积分用户，平均周期按整小时差计算且只筛选完成时间非空，均与当前接口的具体条件不同。核对页面数值应以上述接口口径和 `StatisticsController` 为准。

## 积分与验收

环保积分按 `Math.round(回收重量 × 类别系数)` 计算，历史无类别时系数为 1。正积分写流水，零积分只保留完成记录；积分是参与贡献指标，不是精确碳减排量。

验收时分别核对物品总数、已完成数、回收重量、回收记录数和环保流水总额，再使用跨月发布/完成记录检查趋势。累计值包含超过 12 个月的历史数据，不能要求它总与图中 12 个月合计相等；修改大厅筛选条件也不应改变累计指标。真实验收步骤见 [功能检查指南](11-功能检查与测试指南.md)。
