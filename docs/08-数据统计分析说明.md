# 数据统计分析
统计接口在可重复读事务中计算并展示：累计回收重量、已完成回收次数、物品完成率、平均处理天数、出售/赠送/回收占比、各回收点累计重量、近12个月发布/完成/实际回收重量趋势和环保贡献排行。指标由 `items`、`recycling_orders`、`recycling_records` 和 `eco_point_records` 聚合得到；月度发布按 `published_at`，月度完成按 `completed_at`，月度回收重量按 `recycled_at`，避免把发布月份误称为完成月份。

视图分别统计类别价格和回收点重量；查询文件包含处理方式占比、积分排行、类别循环利用率和平均处理周期，使用 JOIN、GROUP BY、HAVING、子查询和聚合函数。环保积分按“回收重量 × 类别系数”计算，是系统积分而非精确碳减排量。没有数据的月份由后端补为 0，平均处理天数没有有效记录时显示“暂无数据”。
